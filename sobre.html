Sobre o Projeto

Este projeto apresenta um sistema de monitoramento de uma estação meteorológica, permitindo visualizar dados ambientais de forma simples e organizada.

Como Funciona?

A estação realiza a coleta de dados ambientais e apresenta as informações através de um painel de monitoramento.

Componentes Utilizados

  • Sensor de temperatura
  • Sensor de umidade
  • Sensor de pressão
  • Sensor de luminosidade
  • Sensor de chuva

Tecnologias

  • HTML
  • CSS
  • JavaScript
